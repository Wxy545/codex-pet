# 桌宠界面

适用范围：独立桌宠控制中心、聊天、任务与 QQ 设置；负责人：项目维护者；日期：2026-10-30。共同样式在 `src/panel-theme.css`，原生导航在 `src/panel-navigation.*`。沿用原生隔离窗口与现有 IPC，不合并各面板的会话或权限状态。

跟随系统显示模式，深色采用石墨底，浅色采用暖灰底，强调色为克制的紫罗兰。颜色、字体、尺寸和间距从共同变量取得；页面样式只处理布局和业务状态。两套配色分别定义，不能反转整个页面。字体使用系统字体，不下载字体或引入组件框架。

颜色变量为 `--ui-bg`、`--ui-sidebar`、`--ui-surface`、`--ui-raised`、`--ui-field`、`--ui-line`、`--ui-text`、`--ui-muted`、`--ui-faint`、`--ui-accent`、`--ui-accent-hover`、`--ui-accent-ink`、`--ui-success`、`--ui-warning`、`--ui-danger`、`--ui-focus`。间距使用 `--ui-space-1` 至 `--ui-space-8`，依次为 4、8、12、16、20、24、32、40px。圆角使用 `--ui-radius-sm/md/lg`，依次为 6、10、16px。字体使用 `--ui-font`、`--ui-mono`、`--ui-text-xs/sm/md/lg/xl`，字号依次为 11、12、14、16、20px。`--ui-control` 为 40px，`--ui-nav-width` 为 168px；阴影使用 `--ui-shadow`。

左侧导航放产品标识、控制中心、聊天、任务与 QQ 入口，按真实宿主能力显示。导航与标签已经表达所在位置，内容区不重复放标题、欢迎语或用途介绍。设置按角色、互动、碎念及启动联动分开；聊天保留阅读区，输入固定在底部；任务输入、范围和权限在同一工作区，执行进度与结果始终有明确位置。

互动区集中放桌宠显示、全屏自动隐藏与系统监控开关。额度条和 CPU/MEM/GPU 读数位于角色正下方，额度详情按需展开；监控缺失值显示「—」，不能用零或动画代替读数。条目参与窗口边界计算，不能遮住脚底或在拖拽后留在屏幕外。

启动区分开选择运行方式、画面主题和联动应用。主题含跟随应用、ChatGPT、DeepSeek 与 WorkBuddy；本地视频列出文件名和媒体信息，导入、移除、预览各有固定操作。原生 Harness 模式只保留宿主切换入口，隐藏独立桌宠的角色、互动和启动外观。预览不抢真实应用焦点，跳过、Esc、媒体错误和超时均结束声音与画面。

所有主操作区包含等待、忙碌、失败恢复与禁用状态。保留只读默认值、原生目录选择、一次性审批和本机密钥保护。中英文分别使用完整对应文案；用户与模型正文不翻译。支持键盘焦点、减少动态效果、长路径与长内容换行。680px 以下导航收为紧凑横栏，440px 以下表单单列。

验收使用合成内容核对中英文、目标窗口、窄屏、深浅色、键盘与异常恢复。静态样式和模拟数据验证不替代真实任务执行；桌宠原有动画、物理、宿主选择及授权素材保持原有行为。
