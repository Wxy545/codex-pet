# Small launch plan

This is a proposed release plan, not a record of outreach. Codex Pet currently supports Windows only.

1. **Start with three testers.** Ask people who already use Codex on Windows to install from a clean directory. Check first start, follow-start, click/drag, a short chat, one read-only task, and notifications. Record Windows/Codex versions and actionable failures in Issues.
2. **Fix the install path first.** Reproduce and close installation or startup blockers before inviting a larger audience. Keep the repository’s setup instructions usable from one Codex prompt.
3. **Record a 20-second demo.** Use the publicly distributable upstream whale: 0–4s launch; 4–9s a Codex state change; 9–14s click or drag; 14–20s the task result or a notification. Hide personal paths, chat text, usage details, and account information.
4. **Invite feedback through Issues.** Link the install instructions, supported Windows scope, known limitations, and animation contribution guide. Ask for a concrete reproduction rather than general praise.
5. **Consider Show HN after the trial.** A short English post could explain the Codex status bridge, local CLI integration, and what was adapted from dsh-pet. Post only after a maintainer reviews the demo and release. No post has been sent by this plan.

Use original upstream previews with attribution. Do not promote or distribute the experimental dragon artwork until its author has granted permission. Donations support ongoing development; they do not establish a release schedule.
