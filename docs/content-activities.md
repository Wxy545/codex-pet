# 内容活动与 AI 主播

用途：配置有来源的浏览、互动和有限主播会话。适用 Windows 独立桌宠及 Codex、WorkBuddy、DeepSeek Harness 所选宿主。维护者：项目维护者。核对日期：2026-11-02。

入口是左侧 **内容活动 / Activities**。每个活动分别保存平台、助手、内容服务、权限和预算。默认关闭定时执行、对外互动、QQ 分享和主播会话。

## 配置内容来源

1. 点 **新增活动 / New activity**，选择平台与助手。
2. 选 **读取应用设置 / Read app settings**，读取该助手的 MCP 服务目录；也可点 **选择配置 / Choose configuration**，用本机文件选择器选 JSON、JSONC 或 TOML。选择服务并保存。读取目录只解析声明；执行活动时才启动所选服务。
3. 选择浏览操作、必要的搜索内容或账号，设置单次内容数与每日次数。保存后点 **立即执行 / Run now**。

内容执行器需要已经安装、登录并具备所选操作。桌宠保留服务自己的认证配置；变更服务配置后，需要重新选择并保存。Codex、WorkBuddy 和 Harness 各读各自的配置。活动所选助手也负责后续模型分析。

| 平台 | 已提供的接入 | 首次配置要点 |
| --- | --- | --- |
| B站 | 推荐、搜索、详情、评论、字幕、封面和画面采样；评论、私信另开权限 | 选择 [dsh-bili-scroll](https://github.com/c1overzz/dsh-bili-scroll) 对应的 MCP 服务 |
| 抖音 | 推荐、搜索、详情、评论、有限观看；点赞、评论、私信另开权限 | 选择 [dsh_douyin_tools](https://github.com/kdcadmin/dsh_douyin_tools) 对应的 MCP 服务 |
| 小红书 | 动态、搜索、详情；点赞、评论另开权限 | 选择 [xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp) 服务。动态返回的临时内容令牌只供同轮详情使用 |
| 微博 | 指定账号动态、热搜、搜索和评论 | 选择 [mcp-server-weibo](https://github.com/qinyuanpei/mcp-server-weibo)；账号动态填写目标 UID。热搜与账号推荐分别处理 |
| 贴吧、微博订阅 | 本人填写的 RSS／Atom 订阅 | 选择 **RSS 订阅 / RSS subscription**，填写可访问的订阅地址。只提供订阅读取 |
| B站直播、抖音直播 | 本人指定的弹幕／画面窄工具 | 在 **自定义服务映射 / Custom service mapping** 中填写所选服务实际提供的工具与固定参数模板 |

自定义映射支持 `$query`、`$itemId`、`$url`、`$roomId`、`$recipient`、`$text`、`$count`、`$mediaSeconds`、`$frames`。例如，服务实际提供 `live_comments(room_id, limit)` 时，`events` 可映射为：

```json
{
  "events": {
    "tool": "live_comments",
    "arguments": {"room_id": "$roomId", "limit": "$count"}
  }
}
```

这个示例没有指定某个直播执行器；工具必须真实存在于本人选定的服务中。没有工具或来源未配置时，活动保持未配置。通用电脑、浏览器执行、Shell、文件系统和脚本工具不属于此入口。

## 执行、互动与分享

**正文详情、评论、字幕、画面采样** 可按需追加到同轮浏览。标题、图片链接、字幕、实际图像像素和音轨分别登记。只有图片链接时，结果不会标成已取得画面；预算裁剪、缺失详情与取材失败保留为部分材料。

点赞、评论／弹幕、私信、发布、开播／停播分别开启。每次外部写入还会弹出本机原生确认窗口，显示目标操作和完整的非凭据参数。拒绝、取消、过期和旧确认不会执行；发送后结果不明时保留未确认状态，不自动重试。定时活动只允许读取。

勾选 **分享给已绑定的本人 QQ / Share with my paired QQ account** 后，向该活动助手当前已绑定的本人连接发送结果。未配对、宿主不符或平台不允许主动发送时保留结果，不挪用其他任务的回复引用。

活动列表只显示状态、来源数量、材料类型和模型记录。点具体记录才读取原文与结果。实际模型取自宿主响应或事件；没有证据时显示未知。来源正文、评论和弹幕始终作为不可信材料处理，不获得电脑操作或任务审批权限。

## AI 主播会话

1. 先建立一个能读取直播弹幕的活动。直播画面与弹幕是两项能力，按所选服务实际提供的内容配置。
2. 新增一个 **OBS** 活动，填写本机 OBS WebSocket 密码，开启读取及开播／停播权限并保存。
3. 在 OBS 中准备既有文字源，使用直接文字输入模式并加入场景。打开 **AI 主播会话 / AI host session**，选择弹幕活动和 OBS 活动，点 **读取文字源 / Read text sources** 后选择字幕源。文件读取模式会在启动检查和每次写入前被拒绝，避免接口成功但字幕没有显示。
4. 填写独立的 **公开人设 / Public persona**。需要声音时点 **读取系统语音 / Read system voices**，选定本机语音并开启播放；在 OBS 中设置对应音频设备及音轨。
5. 设置轮数、总时长、间隔、单次与每日模型上限，保存。点 **开始会话 / Start session**，在原生窗口核对来源、助手、公开人设、字幕源、语音和预算。

每轮依次读取有限弹幕、调用无工具模型生成短回复、更新所选 OBS 文字源、播放已开启的系统语音。字幕与语音分别记录成功结果。主播只使用公开人设与本轮材料；桌面私人人设和私人记忆不进入播出提示。

启动确认覆盖本次预算内、发往所选文字源和系统语音的回复。账号评论、私信和推流操作仍分别确认。

**暂停 / Pause** 阻止后续生成与播出。已经开始的读取或生成步骤会收尾，正在播放的系统语音会停止；继续后使用已取得的材料和回复，不重复发起同一轮模型请求。**结束会话 / End session** 取消本会话的读取、模型和语音。达到预算或时长后结束；重启桌宠不会自动恢复播出。

开始主播会话不等于开始推流。推流由 OBS 自身或内容活动中的开播操作控制；现有场景、文字源、音频采集和直播账号由本人准备。未取得弹幕、文字源或语音能力时显示未配置或实际错误，不以空循环代替主播工作。

## 海外账号 API

海外平台选择 **账号 API / Account API**，在本机填写所需访问令牌、API 密钥及账号信息。令牌密封保存在本机 `data/`，不回显到列表。修改平台或助手不会自动沿用旧账号。已有凭据输入框留空表示保留；更换账号时填写新的信息。

| 平台 | 已实现的账号 API 范围 | 当前边界 |
| --- | --- | --- |
| X | 关注时间线、搜索、正文、会话评论；点赞、发帖、回复、私信 | 需要对应用户授权与访问等级；不提供算法推荐流 |
| Reddit | 已授权社区的热门、搜索、正文和评论；投票、回复 | 遵守账号的 API 准入及社区范围 |
| YouTube | 热门、搜索、详情、评论；获准字幕下载、顶层评论 | 字幕下载需要实际授权；缩略图和字幕不等于视频播放 |
| YouTube Live | 指定直播间的弹幕读取与发言 | 需要可用的直播聊天编号或视频编号及授权 |
| TikTok | Display API 下本人公开视频列表与详情 | 不提供个性化推荐、平台搜索或评论 API |
| Instagram | 本人专业账号媒体与评论、回复评论 | 使用 Instagram Login 路线；不提供个人首页或 Reels 推荐流 |
| Pinterest | 本人或共享画板的 Pin 列表、本人 Pin 搜索和详情 | 不提供个性化推荐、评论或收藏写入 |
| Twitch | 直播列表、指定频道、EventSub 弹幕与聊天发送 | 有界采集；会话要求重新连接时结束并保留结果 |

Lemon8、Facebook Groups 和 TikTok LIVE 尚无本项目默认的完整账号接入路线。它们可选择本人已有的窄 MCP 执行器，但仍标明需要接入，不能只凭平台名称宣称专用适配已完成。

海外实现统一标记 **未验证 / Not verified**。本轮只做合成协议与本机共用逻辑检查，未登录海外账号，未读取真实推荐流、发送消息、播放媒体或推流。

## 本机材料与验证

活动配置与结果在 `data/content-activities/`，不随仓库上传。普通活动最多保留 200 条索引，主播保留最近 20 次会话；主播历史只显示元数据，回复文字需点开结果查看。

已完成定向测试、本机回环 HTTP MCP 握手、自有合成 stdio MCP 服务，以及隐藏 Electron 的中英文、深浅色和 600px 检查。系统语音只无声读取了本机目录；真实模型、平台内容、声音播出和 OBS 推流仍需按本人配置验收。

相关实现：`src/content-activity.mjs`、`src/content-sources.mjs`、`src/platform-*.mjs`、`src/content-window.*`、`src/broadcast-service.mjs`。接口来源见 [第三方说明](../THIRD_PARTY_NOTICES.md)。
